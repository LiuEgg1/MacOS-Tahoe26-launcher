# MacOS-Tahoe26-launcher
对于MacOS Tahoe的launcher反感？试试我们这个吧！我们以轻量的方式实现了对于原版的启动台的的实现
我们运用mac os原生的swift语言，通过简单的方式实现了对于mac os启动器的模拟，我们并不追求他有多像，但是他还是能用的，至少比原版的要好用的多，符合你们的风格。
这个软件相当的轻量，只有30 Mb，就可以实现对于启动台的模拟，不过这样的话也可能会导致某些功能的缺失，不过不用担心，这一定很好用哦。
软件的一些问题：如何退出这个软件？ 四指上滑退出就好 如果有新的软件存在呢？重新进入一次，它会自动搜索这些软件。
